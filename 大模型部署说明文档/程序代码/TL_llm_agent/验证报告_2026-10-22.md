## 2. 发现的问题与修复

| # | 级别 | 问题 | 修复 |
|---|---|---|---|
| 1 | **严重** | 规则层解析不出目标时，会采用 LLM 猜的 `targetId`。例如“把种子放到那边”，LLM 若猜 `A1-01`，程序会真的去 A1-01。 | 目标必须由规则层解析出来；LLM 猜的目标一律不采用。 |
| 2 | **严重** | 规则层没识别出动作时，会采用 LLM 猜的 `trim_pick/trim_place`。例如只说 `A3-17`，LLM 若猜 `trim_pick`，会驱动叉子。 | 动作以规则层为准；只有目标没有动作时默认 `seed`；LLM 凭空补叉取/放回会被拒绝。 |
| 3 | 高 | 默认 broker/主题就是真实的 `node/arm/01/*`，`--execute` 可能直接让在线真机动作。 | 新增 `--allow-real`；使用真实主题执行必须显式加，否则拒绝连接。 |
| 4 | 中 | “把花篮放到 A4-01”被规则解析成 `trim_pick`（只匹配“放回/放花篮/放置花篮”）。 | 增加“放到/放在/摆/卸”等放置词；同时含叉取+放置时判为动作歧义，拒绝。 |
| 5 | 中 | README 说“急停无需确认”，代码实际仍会问 y/N。 | 急停跳过人工确认，直接发送。 |
| 6 | 低 | README 示例把 A3-17 写成盆号 49。 | 改为盆号 65（48+17）。 |
| 7 | 低 | LLM 有时输出 `targetId: "A401"`（无横杠），日志看起来像错误。 | 规则层目标已作为唯一来源；非法 LLM target 不影响执行。可后续优化 few-shot。 |
| 8 | 信息 | `mock_tl.py` 不写 VLM 快照，mock 链路无法验证 VLM 画面；真实 TL 程序有快照钩子。 | 已在两份 `mock_pick_place.py` 确认 `_save_vlm_frame` 钩子存在；VLM 需在板上实测。 |
| 9 | 信息 | TL 没有 Dobot 那种“已持有同色自动转放置”的状态机。 | seed/seed_place 是完整周期，trim 的忙碌由 TL 回 `retCode=2` 处理，暂不需要；不要照搬 Dobot 的持有逻辑。 |

## 3. 修改内容

文件：`TL_llm_agent/llm_tl_agent.py`

1. `require rule_target`：
   - 目标必须匹配 `A1-01 ~ B4-24` 或 `第X排第Y盆`；
   - LLM 猜的目标不再作为兜底。
2. 动作确定性：
   - `rule_cmd` 为空时，只有 `seed/seed_place/None` 才默认 `seed`；
   - LLM 单独输出的 `trim_pick/trim_place` 被拒绝；
   - 规则与 LLM 动作不一致时按规则执行并提示。
3. `rule_parse_cmd` 花篮动作细化：
   - “把花篮放到/放回 A4-01” → `trim_place`；
   - “叉取 A4-01 的花篮” → `trim_pick`；
   - 同时含叉取和放置 → 动作歧义，拒绝。
4. 新增 `--allow-real`：
   - `--execute` 且主题含 `node/arm/01/*` 时，没有该参数直接退出；
   - 加参数后打印真实主题警告。
5. 急停免确认：
   - `confirm_and_print` 对 `estop` 直接返回 True，不再询问 y/N。
6. 自检新增 4 条安全层测试（假 LLM 注入目标/动作）。

文件：`README.md`、`run_llm_agent.sh`
- 更新真实执行命令为 `--execute --allow-real`；
- 更新安全规则、`--allow-real` 参数、盆号 65、版本记录；
- 明确“无语音”。

新增：
- `SKILL.md`：TL 大模型操作 SKILL（不含语音）。
- 本验证报告。

## 6. 建议

1. 真机第一次只发一条 `seed`，不要连续发多条。
2. 演示/测试永远用 `node/arm/99/*`；真实主题必须加 `--allow-real`。
3. 目标格式只支持 `A3-17` 和 `第三排第十七盆`；新增说法要先扩规则，再放开 LLM。
4. 急停后先停 agent，再用 TL/物理急停恢复；不要连续发任务。
5. 后续若想进一步对齐 Dobot：
   - 可把默认执行改为“直接执行 + `--confirm` 才 y/N”；
   - 可增加本地任务状态（当前 trim 是否进行中）；
   - 但 TL 的 seed 是完整周期，不需要 Dobot 的持有状态机。
6. 语音按你的要求没有加入 TL 版。
