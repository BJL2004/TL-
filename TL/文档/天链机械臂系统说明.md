# 天链机械臂系统说明

> 版本：v1（2026-08-25）
> 适用范围：TCB605 机械臂 + D435 相机 + ROH-LiteS001 灵巧手 + U 型叉子（小车农业机器人）
> 配套：`README.md`（运行手册）、`程序说明文档.md`（程序原理详解）

## 一、天链机械臂示教上位机软件

### 1.1 软件是什么

天链（TCB605）厂商随附的**上位机控制软件**，通过网线与机械臂控制器直连（当前机械臂 IP：`192.168.51.22`，端口 6001/7000 由驱动使用）。它管的是**机械臂本体**：连接、使能、点动、拖拽示教开关、状态查看。

### 1.2 在我们流程中的用途

| 用途 | 说明 |
|---|---|
| 设置机械臂 IP | 改 IP 后上位机重新连接；本系统驱动配置同步改（见 1.4）|
| 使能 / 复位电机 | 上电后先使能才能动；报错时看错误码 |
| 拖拽示教开关 | 示教模式：按住**末端 P 键**即可拖动机臂（ServoJ 释放状态）|
| 单轴点动 | J1-J6 逐轴微调（示教微调用）|
| 关节/笛卡尔状态 | 查看当前角度、坐标，用于核对示教记录 |
| 保存/加载点位 | 本系统不依赖上位机点位（全部走示教文件），此处仅作辅助 |

### 1.3 典型操作流程

```
开软件 → 连接 192.168.51.22 → 电机使能
→ 需要手拖时进入拖拽模式（按末端 P 键拖动，松开即停）
→ 查看/微调关节角度 → 结束后可回到使能/驻留状态
```

### 1.4 与本系统的分工（重要）

| 层 | 软件 | 负责 |
|---|---|---|
| 本体操作 | 天链上位机 | 连接/使能/点动/拖拽/状态查看 |
| 控制驱动 | `run_driver.sh`（tl_driver）| TCP 通信、关节指令、IK 服务（IP 在这里配）|
| 业务程序 | 种子/叉子节点、示教程序 | 视觉定位、周期动作、MQTT 协议 |

⚠️ **同一时间只有一个软件在控制机械臂**：示教/运行节点运行期间，不要用上位机发运动指令。改机械臂 IP 后：上位机重连 + 驱动配置同步改（`~/Desktop/tl_robot_ros2_py-arm/src/tl_driver/` 的 config 和 `tl_driver_node.py`），改完重启驱动。

## 二、手眼标定程序说明

### 2.1 概念与坐标链

相机装在机械臂末端（eye-in-hand），标定得到相机相对 tool0 的位姿矩阵 `T_tool0_camera`：

```
p_base = T_base_tool0 × T_tool0_camera × p_camera
```

### 2.2 三个程序

| 程序 | 作用 | 运行 |
|---|---|---|
| `tl_handeye_collect` | 采集样本（拖拽 25-35 组，静止 2-3 秒按 s）| `ros2 launch tl_hand_deploy handeye_collect.launch.py` |
| `tl_handeye_calibrate` | 求解 + 质量门（exit_code=0 才通过）| `ros2 run tl_hand_deploy tl_handeye_calibrate $DATASET` |
| `tl_handeye_validate` | 九点绝对精度验收 | `ros2 run tl_hand_deploy tl_handeye_validate $LOG --calibration ...` |

### 2.3 采集要求

- 棋盘格 `9×6` 内角点（外角 10×7）、方格 `25mm`、贴刚性平板、固定不动
- 覆盖九宫格 ≥5 格（预览 `coverage=N/9`）、距离 0.3/0.4/0.5/0.6m、双正交方向各 30-60°
- 既要变方向也要变位置；只绕法兰转或只平移都不行

### 2.4 质量门（默认门槛）

| 项目 | 门槛 |
|---|---:|
| 有效样本 | ≥20（建议 25-35）|
| 全局重投影 RMS | ≤0.8 px |
| 基座标定板平移 RMS / 最大 | ≤5 mm / ≤10 mm |
| 基座标定板旋转 RMS / 最大 | ≤0.5° / ≤1.0° |
| TCP 平移/旋转跨度 | ≥120 mm / ≥40° |
| 留一法平移变化 | ≤5 mm |

不合格只生成 `handeye_candidate_rejected.yaml`，不会标记为可用。

### 2.5 九点绝对精度验收

3×3 十字点（间距 60mm）+ 同轴指针：**XY RMS ≤5mm、最大 ≤8mm、Z ≤5mm**。

误差解读：方向一致→常量补偿；随位置系统变化→**必须重标定**（不可用均值掩盖）；随机分散→查数据源。

**铁律：九点验证通过前，禁止灵巧手自动闭合与接触抓取。**

### 2.6 装手后的处理

无手标定得到 `T_tool0_camera`；装手后用 `tl_convert_handeye_frame` 按 `T_flange_tool` 转换到掌心 TCP，转换后**重新做九点验证**；装手导致支架受力变化则直接重做手眼标定。

## 三、灵巧手使用程序说明

### 3.1 硬件与接口

- ROH-LiteS001 六指灵巧手，**RS485 Modbus RTU 从站 2**，波特率 115200
- 经机械臂驱动 ModBus 透传（port 2）控制，写寄存器 `POS_TARGET`（地址 1135）
- 6 个手指各一个目标值（0-65535 位置量程）

### 3.2 三档状态（程序内定义）

| 档位 | 目标值 | 用途 |
|---|---|---|
| 张开 | `0 0 0 0 0 0` | 放种子（释放）|
| 保护握持（力度 1）| `8000 8000 8000 8000 8000 5000` | **默认驻留状态**：待命/移动中/放完立刻回到 |
| 抓取（力度 5）| `35000 35000 35000 35000 35000 25000` | 取种抓稳 |

### 3.3 程序中的使用时机

```
种子节点启动 → 保护握持（防意外全张/全闭）
取种：移到位 → 闭合到力度5 → 抓稳（等待 hand-settle 1.0s）→ 抬起
放种：到位 → 张开(0) → 释放 → 立即回保护握持
新周期开始前：检查手是否还在力度5全闭（是则拒绝命令 retCode 2，防止带着种子乱跑）
```

### 3.4 参数配置（启动器）

| 参数 | 默认 | 说明 |
|---|---|---|
| `--hand-grasp-positions` | `35000×5 + 25000` | 抓取力度 5 |
| `--hand-open-positions` | `0×6` | 完全张开 |
| `--hand-hold-positions` | `8000×5 + 5000` | 保护握持力度 1 |
| `--hand-level5-ratio` | `0.85` | 判定"是否还处于全闭"的阈值比 |
| `--hand-settle-sec` | `1.0` | 手动作后等待稳定的时间 |

⚠️ 力度值按种子/花盆材质可调；抓取力度过大会捏碎种子。九点验证通过前禁止自动闭合。

## 四、机械臂抓取放置种子示教说明

### 4.1 示教（每盆手拖，B → A → P）

```bash
bash ~/Desktop/TL/scripts/teach_seed.sh     # 需驱动先跑
```

| 步骤 | 操作 | 记录内容 |
|---|---|---|
| 启动 | 自动回 A 侧默认起始位（唯一一次自动运动）| — |
| ① 检测位 | 拖到花盆码清晰入镜 → 输入号 → `B`（稳住 2-3 秒）| search_pose（TCP+关节+码位姿+码长 0.054）|
| ② 接近位 | 拖到花盆正上方 → `A` | basket_approach |
| ③ 释放位 | 拖到放种位置 → `P` | basket_release |

- 每按一次立即写入 `~/tl_mock_pick_place/basket_aruco.yaml`（旧版自动进 `archive/`）
- `v` 转 B 侧（J1+180°）；`c` 清空输入；`R` 返回检测位；`Q` 退出（数据已保存）
- 完整 = search_pose + approach + release 全齐；缺任一则运行时报 retCode 3
- A3 排接近位 Y < -710mm 提示 workspace edge：放置偏了就重新教浅 20-40mm

### 4.2 运行（seed / seed_place，MQTT 驱动）

```bash
bash ~/Desktop/TL/scripts/run_seed_mqtt_headless.sh   # 无画面（车端用）
```

一条命令 → 完整周期 → **4 条固定命名反馈**：

| # | 反馈 | 时机 |
|---|---|---|
| 1 | `{"cmd":"seed","targetId":"A2-05","retCode":1}` | 收到命令，开始取种 |
| 2 | `{"cmd":"seed","targetId":"A2-05","retCode":0}` | 取种完成（抓稳）|
| 3 | `{"cmd":"seed_place","targetId":"A2-05","retCode":1}` | 放置响应（识别成功）|
| 4 | `{"cmd":"seed_place","targetId":"A2-05","retCode":0}` | 放置完成 |

周期：固定点取种（力度5）→ 回观测位 → 去目标盆检测位识码（DICT_4X4_250，PnP 动态补偿）→ 接近 → 释放位放种 → 回保护握持 → 回观测位。

### 4.3 关键参数

| 参数 | 默认 | 说明 |
|---|---|---|
| `--fixed-pick-base-mm` | `500 -250.94 58.1` | 取种点 |
| `--final-grasp-z-mm` | `68.937` | 取种下降高度 |
| `--servoj-speed/precision` | `40 / 20` | 快/慢速 |
| `--max-basket-shift-mm` | `200` | 花盆偏移上限 |
| `--marker-sample-spread-mm` | `60` | 采样抖动上限 |

## 五、机械臂叉取花篮剪根程序说明

### 5.1 示教（每盆手拖）

```bash
bash ~/Desktop/TL/scripts/teach_fork.sh
```

| 键 | 记录内容 | 说明 |
|---|---|---|
| `B` | 检测位 | 花篮码清晰入镜 |
| `F` | 叉接近位 | 叉尖到花篮柄上方 |
| `I` | 叉插入位 | 叉子插入花篮柄 |
| `L` | 叉提起位 | 提起花篮 |
| `W` | 搬运中点 | 全局，教一次 |
| `T` | 修剪位 | 全局，教一次（位置1/位置2 两段）|
| `O` | 观测位 | 全局，教一次 |

输出：`~/tl_fork_teach/fork_basket_teach.yaml`（写前自动备份到 `archive/`）。

### 5.2 运行（trim_pick / trim_place）

```bash
bash ~/Desktop/TL/scripts/run_fork_mqtt.sh
```

```
trim_pick  → 目标盆 → 叉入 → 提起 → 高位搬运 → 降到修剪位
             → 位置1修剪 → 挪位置2继续修剪 → 叉住花篮待命
trim_place → 抬到高位 → 搬回原盆 → 放下 → 抽出叉子
```

- 两段式下降：`TL_TRIM_LOWER_CLEARANCE_MM` 控制低位安全间隙（先高位移动、再低速下降，防花篮掉落）
- 反馈：先 `retCode:1`，完成 `retCode:0`，失败 `retCode:3`
- **`active_transfer.yaml` 保护**：叉上真有花篮时启动不自动动，必须先 `trim_place` 放回；空叉误报则删除该文件重启

## 六、VLA 部署

### 6.1 目标

用视觉-语言-动作模型替代"示教姿态 + 识码 + IK"的规则管线，实现**看图（+自然语言）直接输出动作**，泛化到未见过场景（乱序花盆、动态障碍）。

### 6.2 现有数据资产（训练前提）

示教记录天然是"图像-动作"配对（每盆 search_pose 含相机帧 + TCP/关节）；运行周期每次都是成功/失败轨迹样本。→ 升级示教程序为**轨迹记录器**（完整动作序列 + 同步相机帧 + 语言标签）即可自动攒数据集。

### 6.3 部署架构

```
上位机/云端：训练 / 微调 / 蒸馏（OpenVLA / π0 / RDT 等）
车端 Jetson：INT8/FP16 量化小模型推理（≤3B 适合 Orin Nano 8GB）
             或 上位机远程推理（5G/WiFi，延迟目标 <200ms）
输入：D435 彩色/深度 + 关节状态 + targetId（语言化）
输出：动作 → 现有运动安全层 → ServoJ
```

**MQTT 协议不变**——VLA 只替换内部"识码 + IK"段，对车端透明。

### 6.4 路线图

1. 数据规范化（轨迹记录模式、时间戳对齐、语言标签）
2. 模型选型试点（按显存/算力选量化小模型）
3. 离线评测（历史示教数据重放对比）
4. 影子模式（并行推理不执行，指标达标再切换）
5. 灰度上线（先放种后叉修剪；异常自动回退规则管线）

### 6.5 风险

算力不足（大模型需上位机）、数据量不够（需自动化采集）、**VLA 输出必须过安全层**（限幅/到位校验/estop 兜底，不允许绕过）、实时性超标回退。

## 七、安全注意事项

1. **物理 E-stop 始终在手边**；程序级 `estop` 只停运动流，**不是断电**——急停后机械臂仍有重力下垂风险，需人工确认
2. 测试/运行期间**运动路径上禁止站人**；首次跑新周期、新盆位时用慢速 + 旁观
3. 急停锁存设计：`estop` 后所有命令拒绝，**重启节点**才能恢复
4. 九点验证通过前**禁止灵巧手自动闭合与接触抓取**（防夹伤/损坏）
5. 手眼标定、示教、改 IP 等任何物理变更后，**先低速单点验证再全自动跑**
6. 示教时按住末端 P 键拖动，松开即停；拖不动时检查是否处于使能/驻留状态
7. 公网 MQTT 凭据（`shapandevice`）不要外泄；生产环境建议换私有 broker
8. D435 线缆固定，避免运动时拉扯（影响标定与识别）
9. 码贴正、花盆固定；码卷曲/反光会导致识别失败（retCode 3）
10. 设备断电顺序：先停节点 → 关驱动 → 再断电；避免数据文件写入中断（示教记录写一半会丢，靠 archive 备份找回）
