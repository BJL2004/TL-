3、bash ~/Desktop/TL/scripts/teach_seed.sh
  手拖机械臂 → 让 29 号花盆的码清晰完整入镜（画面中间最好），键盘输入 29（数字键，窗口下方显示 "Basket number buffer: 29"），按 B。
  拖 + A（记录接近位），拖 + P（记录释放位）。
  键	作用
  0-9	输入花盆号（最多 3 位）
  c	清空输入缓冲
  B（或 D）	选中并记录检测位
  A / P	记录接近位 / 释放位
  v	自动运动到 B 侧起始位（J1 转 180°，教 B1-B4 排用）
  R	自动返回当前选中盆的检测位（唯一会动机械臂的键之一）
  Q / Esc	退出（数据早已实时保存，Q 只是关窗口）
4、叉花篮示教
  bash ~/Desktop/TL/scripts/teach_fork.sh
  操作：
  拖到花篮处 → 输入花盆号 → B 检测位 → F 接近 → I 插入 → L 提起；W 搬运中点、T 修剪位、O 观测位（全局，教一次）；R 返回；Q 保存。
