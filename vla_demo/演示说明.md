# VLA 演示一天方案 · 运行手册（SmolVLA 零样本 · 全本地）

> 目标：Nano 本地跑 SmolVLA（开源 VLA，450M），D435 看图 + 语言指令 → 机械臂朝目标小幅移动。
> 只演示"能动/能跟随"，不要求抓取。**不修改任何现有程序**，本文件夹独立。

---

## 0. 文件清单（本文件夹）

| 文件 | 说明 |
|---|---|
| `tcb_find_infer_server.py` | 推理服务：skeleton / demo / **smolvla 零样本** / 微调checkpoint 四种模式 |
| `tcb_find_policy_node.py` | 执行节点：原版基础上加 `--stop-on-zero`、`--velocity`（其余一致） |
| `install_nano_smolvla.sh` | Nano 一键装环境（防覆盖 GPU torch + 国内镜像） |
| `演示说明.md` | 本文件 |

## 1. 拷到 Nano

Windows 端（PowerShell/CMD）：

```powershell
scp -r C:\Users\DragonAfterAll\Desktop\vla_demo nvidia@<Nano的IP>:~/Desktop/
```

拷完后在 Nano 上：`chmod +x ~/Desktop/vla_demo/*.sh`

## 2. 装环境（一次性，10~30 分钟，主要是下载）

```bash
bash ~/Desktop/vla_demo/install_nano_smolvla.sh
```

## 3. 自检（不动机械臂）

```bash
cd ~/Desktop/vla_demo
python3 tcb_find_infer_server.py --policy smolvla --check
```

看到 `[自检] ... 假数据动作输出: [...]` 就说明模型能加载能出数。
（首次加载约 10~30 秒；输出接近 0 也正常，真实画面下才有意义。）

## 4. 正式演示流程（三个终端）

```bash
# 终端 1：驱动（照旧）
bash ~/Desktop/TL/scripts/run_driver.sh

# 终端 2：推理服务（约 10~30 秒就绪）
cd ~/Desktop/vla_demo
python3 tcb_find_infer_server.py --policy smolvla --port 18080

# 终端 3：执行节点，先干跑（只打印不动臂）
source ~/Desktop/tl_robot_ros2_py-arm/install/setup.bash
cd ~/Desktop/vla_demo
python3 tcb_find_policy_node.py --task "pick up the red cube" \
    --dry-run --max-step-mm 15 --loop-hz 1
```

干跑看着动作数值合理（有方向、不过大）后，真跑：

```bash
python3 tcb_find_policy_node.py --task "pick up the red cube" \
    --execute --max-step-mm 15 --loop-hz 1 --max-steps 30
```

> 手放急停旁；桌面放一个**红色方块**进 D435 视野；跑满 30 步或按 `q` 结束。

## 6. 常见问题

| 现象 | 处理 |
|---|---|
| 推理服务打印 `运行在 CPU!` | torch 被覆盖：重装 jetson-ai-lab GPU wheel（装环境脚本第 1/3 步会帮你看） |
| 模型下载卡住 | `export HF_ENDPOINT=https://hf-mirror.com` 后重试 |
| `找不到 SmolVLA 模块` | lerobot 没装成功：重跑 `install_nano_smolvla.sh` |
| 动作总是接近 0 | 加大放大系数：`--action-scale 600`（先 `--check` 看输出） |
| 动作太跳/太猛 | `--smooth 0.5`；执行端已限幅 15mm/步，双保险 |
| 执行节点报 `推理失败` | 确认终端 2 服务在跑；`curl 127.0.0.1:18080/health` |
| 机械臂不动但日志在刷 step | 检查驱动是否在跑、moveL 是否被拒（看终端 1） |

## 7. 时间表（一天）

| 时段 | 事项 |
|---|---|
| 0.5h | 拷文件 + 开跑安装脚本（挂着下载） |
| 0.5~1h | 自检通过（`--check` 出数） |
| 1~2h | 干跑调参（`--action-scale` / `--smooth`），看数值合理 |
| 2~4h | 低速真跑 + 摆红方块微调演示效果 |
| 4~5h | 话术彩排：装模型 → 看图说话 → 臂朝方块动 → 安全限幅说明 |
| 剩余 | 彩排 2~3 遍 + 保底模式演练 + （可选）录备用视频 |

## 9. 安全红线

- 物理急停始终在手边；**先 dry-run 再 execute**；
- 运动范围内不站人、不放贵重物；首次跑 `--max-step-mm 10` 更稳；
- 本演示动作无任务语义（零样本），**只做展示**，不要用于实际作业。
