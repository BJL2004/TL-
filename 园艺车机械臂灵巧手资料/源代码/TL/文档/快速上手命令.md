# 快速上手命令（2026-10-08 更新）

> 前提：驱动先起；E-stop 在手边；同一时间只开一个程序。
> 脚本从 Windows 拷过去后先执行一次：`chmod +x ~/Desktop/TL_lowerobs_test/scripts/*.sh`

## 一、种植种子

1. 先运行机械臂驱动（二选一，同一个驱动）：
```bash
bash ~/Desktop/TL/scripts/run_driver.sh
# 或
ros2 launch tl_driver tl_tcb605_driver.launch.py
```
2. 运行抓取种子、放置种子命令：
```bash
# ★ A3 排的盆必须用新版：
bash ~/Desktop/TL_lowerobs_test/scripts/run_seed_mqtt.sh
# 其余盆用老版（也可统一用新版）：
bash ~/Desktop/TL/scripts/run_seed_mqtt.sh
```

## 二、叉取花篮

1. 先运行机械臂驱动（同上，二选一）。
2. 运行叉取花篮命令：
```bash
bash ~/Desktop/TL_lowerobs_test/scripts/run_fork_mqtt.sh
```

## 三、示教

```bash
# 1) 种子示教（★ A3 排必须用新版；教其余上排盆推荐老版）：
bash ~/Desktop/TL_lowerobs_test/scripts/teach_seed.sh
bash ~/Desktop/TL/scripts/teach_seed.sh
# 2) 叉子示教（统一用新版）：
bash ~/Desktop/TL_lowerobs_test/scripts/teach_fork.sh
```

## 四、查已示教点位（只读，不动机械臂）

```bash
bash ~/Desktop/TL_lowerobs_test/scripts/list_taught.sh
```

## 五、发一条命令（另开终端；一次一条，等它跑完再发下一条）

```bash
# 放种子（A3 已教点，用新版跑）
mosquitto_pub -h 116.205.245.172 -p 1883 -u shapandevice -P 'qwer1234!!' \
  -t node/arm/01/down -m '{"cmd":"seed","targetId":"A3-17"}' -q 1

# 叉花篮（30 号 = A2-06，已教全套；会停在修剪位 2 等剪根）
mosquitto_pub -h 116.205.245.172 -p 1883 -u shapandevice -P 'qwer1234!!' \
  -t node/arm/01/down -m '{"cmd":"trim_pick","targetId":"A2-06"}' -q 1
# 剪完放回
mosquitto_pub -h 116.205.245.172 -p 1883 -u shapandevice -P 'qwer1234!!' \
  -t node/arm/01/down -m '{"cmd":"trim_place","targetId":"A2-06"}' -q 1
```

## ★ 注意

1. **A3 排码贴反已修正**：发 `A3-01` 用的就是第 1 格上贴的 ID71；之前教的两个点现在叫 **A3-17 / A3-11**（日志会打印 `Reversed-row mapping: …` 换算行）。
2. **A3 排（以及以后做的下排盆 A1/A4/B1/B4）的教与跑都用新版**，老版没有换算。
3. 叉子示教键序：第一盆 `编号→B→F→I→L→W→T→R`，以后每盆 `编号→B→F→I→L→R`；`O`=待机位（种球默认位）、`v`=去 A/B 起始位（老观测位 `-83.668… / 96.332…`）、`g`=下排观测位。
4. 动作没走完不要按 Ctrl+C（等 `Arrived:` / `Returned:` 打印完再操作）。
5. 就绪标志：驱动 = 终端持续刷状态；运行程序 = 打印 `MQTT connected and subscribed`。
6. **识别位置规则（上排/下排检测位）**：**上排盆**（A2/A3/B2/B3）没有观测位——运行时**直接去该盆检索位**识别；**下排盆**（A1/A4/B1/B4）**先去对应侧下排观测位**识别（教时按 `d` 记录、`g` 验证），识别完再回检索位。

## 六、示教的要求和注意事项

### 【种子示教】（灵巧手）

**开始前（要求）**
- 驱动先起；**示教和运行互斥**（同一时间只开一个程序）；E-stop 在手边；
- 教 **A3 排**和**下排盆（A1/A4/B1/B4）用新版**；教其余上排盆推荐老版；
- 启动后臂自动去 A 侧起始位；**按键前先点一下相机窗口**（键盘焦点要在窗口上，在终端里敲没用）；
- 下排盆额外前置：按 `v` 确认侧 → 拖到能看清下排码处 → 停稳 → 按 `d` 记录 → 按 `g` 验证（B 侧可不记，运行端自动按 A+180° 推导）；
- A3 排：编号按"物理第几格"输；按 `B` 时看有没有 `Reversed-row mapping: …` 打印——**没有这行就别用这个程序教 A3**。

**每盆要点（拖 → 输编号 → B → A → P → R）**
- 拖到位后**松手、停稳 1~2 秒再按键**（否则报"看不清/样本不稳"、`/tcp_pose is stale`）；
- `B`：必须看到 `Selected basket number=…` 才算锁定成功；
- `A` 落种接近位：花盆正上方合适高度；
- `P` 落种释放位：伸进盆口放种位置，必须看到 `xx mm below`（正数）；
- 每盆按 `R` 回检索位验证一下再教下一盆；`c` 清空输入、`Q` 退出。

**注意**
- 码要看清：距离 30~50cm、有白边、别反光/被挡；看不清就换角度再按 `B`；
- **同一盆重教 = 覆盖旧值**；教的数据实时落盘；
- **种子教过 ≠ 叉子教过**，两套流程各教各的；
- 动作没走完不要按 Ctrl+C；教完用 `list_taught.sh` 核对。

### 【叉子（花篮）示教】

**开始前（要求）**
- 统一用新版 `teach_fork.sh`；启动日志应含 `Reversed-row code mapping active: ['A3']`；
- 启动后**不动臂**；只有 `O / v / g / R` 会自己动，其他键全靠手拖；
- 按键前先点一下相机窗口；
- 待机位：按一次 `O` 刷新（= 种球默认位）；**`O` 不是去看花篮**——去花篮排前面按 `v`（A/B 起始位 `-83.668… / 96.332…`）；
- 要教下排盆：先记录下排观测位（`v → 拖 → d → g`）。

**每盆要点**
- `B` 前：拖到能看清码、且站位方便伸叉的地方，停稳 1~2 秒；
- `I / L` 有校验：水平 ≥20mm、竖直 ≥30mm、漂移 ≤60mm、姿态变化 ≤25°——拖得不够直/不够远会被拒（`horizontal travel is only…`），**重新拖到位再按**即可；
- 第一盆必须连教 `F → I → L → W → T`（W 在 L 之后、T 在 W 之后）；下排盆的第一盆按 W/T 会自动存成"下排专用"；
- 以后每盆只按 `编号 → B → F → I → L → R`；**W/T 不要再按**（重按会覆盖对应那一对）；
- 修剪位 1 / 2 **不用教**（程序里写死）。

**注意**
- 花篮在叉上时（L/W/T 阶段）`d / g / v / O` 会被拒绝（提示 `the basket is on the fork; press R …`）→ 先按 `R` 收尾；
- 教 B 区盆：先按 `v` 到 B 侧起始位（A 侧状态下第一下 `v` 先去 B、再按一下回 A——看终端打印确认）；
- 每盆结束按 `R`（等 `Returned: max joint error=…` 打印完）再做下一盆；
- 动作没走完不要按 Ctrl+C；教完用 `list_taught.sh` 核对（每盆应有 F/I/L 三行，全局/下排各有 W、T 一行）。

**通用**：示教 / 运行互斥；**教完后重启运行程序再发命令**；物理 E-stop 始终在手边。
