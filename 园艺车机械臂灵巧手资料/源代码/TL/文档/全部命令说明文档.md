### 4.3 每盆操作（拖 → 号 → B → A → P → R）
```
1. 手拖到码清晰入镜（30-50cm、带白边、稳 2-3 秒）
2. 输入编号（A 区 1~96 / B 区 97~192 三位数直接输；**A3 排按"物理第几格"输**）
3. 按 B   ← 必须看到 "Selected basket number=你输的号"
   ★ A3 排按 B 时会先打印一行换算：Reversed-row mapping: position number 56 -> actual code number 65 (ID64)。
     没有这行 = 你跑的是老版程序（A3 别用它教）
4. 拖到花盆正上方 → 按 A
5. 【降下去】拖进盆口放种位置 → 按 P   ← 必须看到 "xx mm below"（正数）
6. 按 R 回检索位 → 下一盆
```
**其他键**：`v` 转 B 侧（J1+180°）｜`c` 清空输入｜`Q` 退出（实时落盘）
**下排盆（A1/A4/B1/B4）额外前置**（新版）：先记录下排观测位——拖到能看清下排码处 → 停稳 → 按 `d`（核对打印 `side=A`）→ 按 `g` 验证；B 侧不必记录（运行端自动按 A+180° 推导）。

**A/B 区域**：
| 区域 | 编号 | 机械臂朝向 |
|---|---|---|
| A 区（A1-A4）| 1~96 | J1 ≈ -83° |
| B 区（B1-B4）| 97~192 | 按 `v` 转 +180° |

| 键 | 记录内容 |
|---|---|
| 编号 + `B` | 输花篮号（1~192；A3 排按"第几格"输，按 B 时自动换算并打印）→ 选定（锁码 + 记检索位）|
| `F` | 叉接近位 |
| `I` | 叉水平插入位（校验：水平 ≥20mm）|
| `L` | 叉竖直抬起位（校验：竖直 ≥30mm）|
| `W` | 高位载运点（举着花篮走路的高点；**上排/下排各教一次**——教下排盆时自动存"下排专用"）|
| `T` | 暂放位（搬运链中转点；同样上下排分开；**必须在 W 之后按**）|
| `O` | 去**待机位**（= 种球默认位 `[-23.246, …]`）并记录；**不是看花篮的位置** |
| `v` | 切 A/B 侧（去该侧起始位 `-83.668… / 96.332…`，即老"观测位"；教花篮从这里开始）|
| `d / g` | 记录 / 回到当前侧**下排观测位**（看下排盆的码）|
| `R` | 回检索位（等 `Returned: max joint error=…` 才算走完）；`Q` 保存退出 |

第一盆：`编号 → B → F → I → L → W → T → R`；以后每盆：`编号 → B → F → I → L → R`（W/T 不用重按，重按会覆盖）。
**修剪位 1 / 2 不用教**：写在 `fork_basket_cycle.py` 顶部常量里（示教器读数，2026-10-07 更新）。

```bash
# 灵巧手通信自检（读固件）
python3 - <<'EOF'
import rclpy, time
from rclpy.node import Node
from tl_ros2_interface.msg import ModbusMasterParam, ModbusRTUParam
from tl_ros2_interface.srv import ModbusRead
rclpy.init(); n = Node("hand_check")
c = n.create_client(ModbusRead, "/tl_driver/modbus_read")
r = ModbusRTUParam(); r.slave_id=2; r.port=2; r.baudrate=115200
r.data_bit=8; r.stop_bit=1; r.check_bit="None"
m = ModbusMasterParam(); m.type="RTU"; m.start_addr=True; m.rtu=r
req = ModbusRead.Request(); req.master_id=1; req.addr=1001; req.quantity=1; req.master_param=m
f = c.call_async(req); rclpy.spin_until_future_complete(n, f, timeout_sec=3.0)
print("固件:", f.result().data if f.done() and f.result() and f.result().success else "无响应（查RS485/供电）")
n.destroy_node(); rclpy.shutdown()
EOF
```
