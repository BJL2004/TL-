# 基于单机械臂与眼在手单摄像头的轻量级VA模型自主抓取系统设计方案

---

# 1. 项目背景

近年来，视觉-语言-动作（Vision-Language-Action，VLA）模型已成为机器人自主操作的重要研究方向。OpenVLA、RT-2、GR00T、π0 等模型能够根据自然语言、视觉输入直接生成机器人动作，实现端到端智能操作。然而，该类模型通常具有数十亿参数，对GPU显存及计算资源要求极高，难以部署于边缘计算平台。

本项目采用 **Jetson Orin Nano 16GB（157 TOPS）** 作为机器人控制平台，配置 **TCB605 六自由度机械臂**、**Intel RealSense D435 深度相机（Eye-in-Hand）** 和 **ROH-LiteS001 灵巧手**。综合考虑硬件算力、实时性及部署难度，拟采用 **Vision-Action（VA）模型** 替代完整VLA模型，实现单摄像头自主抓取，并预留语言模型接口，为后续升级至轻量级VLA系统奠定基础。

---

# 2. 系统总体架构

整个系统采用 **"视觉感知—动作决策—机器人执行"** 三层架构。

```text
                  用户任务（可选）
                       │
             （后续可接入Qwen2.5-VL）
                       │
               Vision Encoder
                       │
                Transformer
                       │
               Action Decoder
                       │
          Future Joint Actions
                       │
                  ServoJ控制
                       │
                 六轴机械臂执行
                       │
                  灵巧手抓取
```

其中：

- **Vision Encoder**：提取RGB图像特征；
- **Transformer**：学习视觉信息与机器人动作之间的映射关系；
- **Action Decoder**：预测未来多个关节动作；
- **ServoJ**：实现机器人连续轨迹控制；
- **Eye-in-Hand相机**：持续提供机器人第一视角图像。

与传统视觉抓取不同，该系统无需目标检测、三维定位及逆运动学求解，实现真正意义上的端到端视觉抓取。

# 3. 硬件组成

| 模块 | 型号 |
|------|------|
| AI计算平台 | Jetson Orin Nano 16GB（157TOPS） |
| 机械臂 | TCB605 六自由度机械臂 |
| 相机 | Intel RealSense D435 |
| 灵巧手 | ROH-LiteS001 |
| 通讯框架 | ROS2 Humble |

其中，相机安装于机械臂末端，属于 **Eye-in-Hand（眼在手上）** 结构。

## Eye-in-Hand优势

- 相机视角始终固定；
- 无需多摄像头协同标定；
- 非常适合端到端策略学习；
- 可减少环境变化带来的影响；
- 当前ACT、Diffusion Policy等机器人学习方法均采用该方案。

# 4. 当前系统分析

目前已经完成传统视觉抓取流程：

```text
RGB图像
    │
YOLO目标检测
    │
目标中心
    │
Depth深度
    │
空间坐标
    │
手眼标定
    │
机器人坐标
    │
逆运动学
    │
关节角
    │
ServoJ
```

## 当前方案优点

- 技术成熟；
- 可解释性强；
- 易于调试。

## 当前方案存在的问题

1. 依赖YOLO检测精度；
2. 依赖深度相机测距精度；
3. 依赖高精度手眼标定；
4. 多模块误差逐级累积；
5. 系统复杂，维护成本高。

因此，计划采用 **Vision-Action（VA）模型** 替代传统Pipeline。

---

# 5. VA模型设计

系统整体网络如下：

```text
RGB Image
      │
Vision Encoder
      │
Transformer
      │
Action Decoder
      │
Joint Actions
      │
ServoJ
```

模型输入：

- RGB图像
- 当前机器人状态（Joint）

模型输出：

- 下一时刻关节动作
- 或未来N步关节动作序列

即直接学习：

```text
Image
    │
    ▼
Robot Action
```

相比传统方案：

| 传统方案 | VA方案 |
|----------|--------|
| YOLO检测 | × |
| 深度定位 | × |
| 三维坐标计算 | × |
| 手眼标定依赖 | 极低 |
| IK逆运动学 | × |
| Action预测 | √ |

# 6. 数据采集方案

## 6.1 当前采集方式

当前采集：

```text
Image
     │
     ▼
Goal Joint
```

属于典型Behavior Cloning，只能学习：

```text
Image → Goal
```

无法学习整个抓取过程。

---

## 6.2 改进后的采集方式

建议采用轨迹采集。

每一帧记录：

```text
RGB Image

Joint

TCP Pose

Gripper State

Timestamp
```

整个抓取过程：

```text
观察

↓

接近目标

↓

下降

↓

闭合夹爪

↓

抬升

↓

返回
```

最终形成：

```text
Image₀
Joint₀
Action₀

↓

Image₁
Joint₁
Action₁

↓

Image₂
Joint₂
Action₂

......

↓

Imageₙ
Jointₙ
Actionₙ
```

---

## 6.3 建议采集参数

| 参数 | 建议值 |
|------|--------|
| 采样频率 | 50Hz |
| 单条轨迹 | 2～5秒 |
| 每条轨迹帧数 | 100～250帧 |
| 数据量下限 | 200条 |
| 推荐数据量 | 500条 |
| 最佳数据量 | 1000条以上 |

# 7. 模型选型分析

| 模型 | 参数规模 | Jetson部署 | 推荐程度 |
|------|----------|------------|----------|
| BC（ResNet18） | ≈20M | ⭐⭐⭐⭐⭐ | ⭐⭐⭐⭐ |
| ACT | ≈80M | ⭐⭐⭐⭐⭐ | ⭐⭐⭐⭐⭐ |
| TinyVLA | ≈100M | ⭐⭐⭐⭐⭐ | ⭐⭐⭐⭐⭐ |
| Diffusion Policy | ≈100M | ⭐⭐⭐⭐ | ⭐⭐⭐⭐ |
| OpenVLA | >7B | ⭐ | ⭐ |
| RT-2 | >7B | ⭐ | ⭐ |
| GR00T | >7B | ⭐ | ⭐ |
| π0 | >7B | ⭐ | ⭐ |

## 推荐模型：ACT

推荐理由：

- 参数规模适中；
- 数据需求较低；
- 已被大量机器人平台验证；
- 可直接导出ONNX；
- TensorRT部署成熟；
- Jetson能够实现实时推理（20~40 FPS）。

# 13. 总结

综合硬件平台、软件架构及当前项目进展分析，本项目采用 **Eye-in-Hand + Vision-Action（VA）模型** 的技术路线具有较高可行性。

相比直接部署OpenVLA等大型VLA模型，该方案具有以下优势：

- 部署难度低；
- 对Jetson算力友好；
- 实时性能高；
- 易于训练；
- 可逐步扩展至轻量级VLA系统。

最终形成一套适用于边缘计算平台的端到端自主抓取系统，为机器人智能操作提供可扩展的技术方案。
