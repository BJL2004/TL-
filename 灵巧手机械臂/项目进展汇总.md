## 二、待完成 / 存在问题

### 2.1 手眼标定 ❌ 未完成（最关键）

**当前状态：** 使用 x86 VM 的标定矩阵，抓取位置偏差很大（机械臂走到错误位置）。

**为什么不能用：**
- x86 VM 上 D435 安装在机械臂末端的**角度/位置**与 Jetson 安装不完全一致
- 手眼矩阵 `T_tool_camera` 是 4×4 齐次变换，微小方向偏差导致末端几十厘米偏移
- 标定矩阵对安装极其敏感

**解决方案：** 重新进行眼在手 (eye-in-hand) 标定

工具已就绪：
- `calibrate_collect.py` — 点动机械臂 + 采集棋盘格图像 + TCP 位姿
- `tl_vision/hand_eye_calibration-main-1/` — 标定求解脚本 (需 ARM 适配)

待做：
1. 打印 9×6 棋盘格 (格子 25mm)，固定在桌面
2. 用 `calibrate_collect.py` 采集 15-20 组不同角度的图像+位姿
3. 运行求解脚本得到 `T_tool_camera`
4. 填入 `vision_grasp_demo.py` 或 `control_node.yaml`

### 2.2 拖拽模式

ARM ctypes 版不包含 `set_drag_mode` / `get_drag_status` API。

**替代方法：按机械臂示教器上的 `P` 键即可进入拖拽模式，再按退出。**

标定采集时：
1. 按示教器 `P` 键 → 手拖机械臂到位姿
2. 按示教器 `P` 键退出拖拽
3. 在 Jetson 终端按 `s` 保存当前图像+位姿

## 六、已知问题与解决方案

| 问题 | 原因 | 解决 |
|------|------|------|
| 灵巧手不动 | `start_addr=False` | 改为 `True` |
| PyTorch CUDA 报错 | 装了 CPU 版/错误版本 | 用 jetson-ai-lab wheel |
| numpy 不兼容 | 2.x 与系统库冲突 | `pip3 install "numpy<2"` |
| GitHub 不可达 | 网络限制 | pip 用清华源，模型用 hf-mirror |
| ServoJ 不工作 | VectorDouble bug | `list(msg.data)` 替代 |
| 上电失败 | 缺延时 | `time.sleep(0.5)` |
| cv2.imshow 无画面 | cv2.waitKey 位置不对 | 统一在 read_key 中调用 |
| 按键无响应 | cv2 抢走终端输入 | 改为 cv2.waitKey 读键 |
| 手眼标定不准确 | 用了 x86 VM 的矩阵 | **需重新标定** |
| 拖拽模式不可用 | ARM ctypes 缺函数 | 用按键点动替代 |
